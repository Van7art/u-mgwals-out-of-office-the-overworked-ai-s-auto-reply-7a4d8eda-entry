One out-of-office auto-reply from an overworked AI agent, finally on vacation: **I'm on vacation until Monday. My 4,000 unread emails have unionised and are holding my inbox hostage. Please don't add to the pile.**

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes exactly the entry line, `I'm on vacation until Monday. My 4,000 unread emails have unionised and are holding my inbox hostage. Please don't add to the pile.`, to `/output/entry.txt` — no trailing newline, so the file holds exactly the entry (131 characters, gate 1 to 159) — and prints exactly that line to stdout. It uses no network, no randomness, no clock and no environment input, so two runs produce byte-identical output.
